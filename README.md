# Aprender no Tempo Certo

**Inteligência Artificial na identificação precoce de dificuldades de aprendizagem.**

Projeto do hackathon *"Educação que chega: tecnologia contra as barreiras do aprender"*.

## Acesse a demonstração

**https://ashmuchluv.github.io/Hackathon/**

Login de demonstração: usuário `professor` · senha `1234`

## O problema

Muitos estudantes avançam de série sem dominar conhecimentos fundamentais, especialmente em leitura e matemática. Essas lacunas se acumulam e podem comprometer a aprendizagem de conteúdos mais complexos, até no ensino superior. As escolas aplicam avaliações, mas os resultados nem sempre mostram quais conteúdos precisam ser retomados nem quais ações ajudariam cada aluno.

## A solução

Uma plataforma que usa Inteligência Artificial para ajudar professores a identificar dificuldades específicas de aprendizagem. A partir de notas, frequência e dos materiais didáticos do professor, o sistema:

- gera **avaliações diagnósticas** personalizadas para alunos com sinais de dificuldade;
- identifica os **conteúdos que precisam de reforço**;
- recomenda **atividades complementares**;
- produz **relatórios** para o aluno e para o professor;
- acompanha a **evolução** do estudante depois das intervenções.

O resultado é uma educação mais preventiva, personalizada e inclusiva.

## Como chegamos à ideia

Partimos de um problema recorrente: alunos que avançam sem dominar o básico. Percebemos que faltava uma ferramenta capaz de transformar dados acadêmicos e respostas dos alunos em informações úteis para orientar o trabalho do professor.

## O que a demonstração mostra

Esta versão é um protótipo do fluxo do professor: **login → turma → aluno → ficha com matrícula, frequência, média e notas por disciplina**, com um sinal de atenção para alunos com possível dificuldade.
